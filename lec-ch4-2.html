4.4.5 Flexbox 布局：现代网页布局的核心

Flexbox（弹性盒子布局）是现代网页最常用的布局方式，AI 生成的代码 90% 都用它。你不需要精通，但要能看懂。

.container {
  display: flex;           /* 开启弹性布局 */
  flex-direction: row;     /* 主轴方向：row横向（默认）、column纵向 */
  justify-content: center; /* 主轴对齐：flex-start左、center中、flex-end右、space-between两端对齐 */
  align-items: center;     /* 交叉轴对齐：flex-start顶、center中、flex-end底、stretch拉伸 */
  gap: 16px;               /* 子元素之间的间距 */
  flex-wrap: wrap;         /* 子元素太多时是否换行 */
}

.item {
  flex: 1;                 /* 子元素占据的比例：1表示平分 */
}

常见布局模式

布局CSS效果
完全居中display:flex; justify-content:center; align-items:center;子元素水平垂直都居中
两端对齐display:flex; justify-content:space-between;第一个靠左，最后一个靠右
导航栏display:flex; justify-content:space-between; align-items:center;左边logo，右边菜单，垂直居中
卡片网格display:flex; flex-wrap:wrap; gap:16px;卡片自动排列，一行放不下就换行

4.4.6 响应式设计：手机电脑都好看

响应式设计就是让网页在不同屏幕尺寸上都能正常显示。核心是媒体查询（Media Query）：

/* 默认样式：电脑端 */
.container {
  width: 800px;
  margin: 0 auto;
  display: flex;
  gap: 20px;
}

/* 当屏幕宽度小于等于 768px 时（平板和手机） */
@media (max-width: 768px) {
  .container {
    width: 100%;
    padding: 0 16px;
    flex-direction: column; /* 从横向变成纵向 */
  }
}

响应式关键原则：

  1. HTML head 里必须有 <meta name="viewport" content="width=device-width, initial-scale=1.0">
  2. 宽度用百分比（%），少用固定 px
  3. 图片自适应：img { max-width: 100%; height: auto; }
  4. 用 flex-wrap: wrap 让元素自动换行

4.4.7 CSS 常见错误

⚠️ 注意

错误1：选择器写错

class 选择器忘了点号：card { ... } → 应该是.card { ... }。

错误2：属性值忘了单位

font-size: 24 → 应该是font-size: 24px。

错误3：margin: 0 auto 不居中

margin: 0 auto 只能水平居中块级元素，而且元素必须有明确的 width。

错误4：忘记加 transition 就想有动画

设置了 hover 样式但没有 transition，颜色是突变的。需要在默认样式里加 transition: all 0.3s ease;。

4.5 JavaScript：网页的肌肉

4.5.1 JS 能做什么

在 Vibe Coding 的项目中，JS 主要做这些事：

  • 响应交互：点击按钮、输入文字时执行操作
  • 操作页面元素：添加/删除/修改页面上的内容
  • 数据存储：把数据保存到浏览器本地（localStorage），刷新不丢失
  • 表单验证：检查用户输入是否合法

4.5.2 JS 的基本语法

变量和数据类型

const name = "张三";        // const：常量，不能重新赋值
let age = 20;               // let：变量，可以重新赋值
// 不要用 var（老方式，有问题）

const str = "你好";          // 字符串

const bool = true;           // 布尔值
const arr = [1, 2, 3];      // 数组
const obj = { name: "张三", age: 20 };  // 对象

函数

function greet(name) {
  return "你好，" + name;
}
const result = greet("张三");

// 箭头函数（AI 常用）
const add = (a, b) => a + b;

条件判断和循环

if (score >= 90) {
  console.log("优秀");
} else if (score >= 60) {
  console.log("及格");
} else {
  console.log("不及格");
}

// 遍历数组（最常用）
const fruits = ["苹果", "香蕉", "橙子"];
fruits.forEach((fruit, index) => {
  console.log(index + ": " + fruit);

const person = { name: "张三", age: 20 };

person.age = 21;        // 修改
person.city = "北京";   // 添加

4.5.3 DOM 操作：JS 控制网页的核心

DOM是浏览器把 HTML 转换成的树形结构。JS 通过 DOM 来读取和修改页面元素。

获取元素

const button = document.getElementById('myButton');  // 通过 id
const firstCard = document.querySelector('.card');     // 第一个匹配的（CSS选择器）
const allCards = document.querySelectorAll('.card');   // 所有匹配的

修改元素

const title = document.getElementById('title');
title.textContent = '新的标题';        // 改文字（推荐，安全）
title.style.color = 'red';             // 改样式
title.classList.add('highlight');      // 添加 class
title.classList.remove('highlight');   // 删除 class
title.classList.toggle('highlight');   // 切换 class

创建和删除元素

const newDiv = document.createElement('div');
newDiv.textContent = '我是新创建的';
newDiv.className = 'item';
container.appendChild(newDiv);   // 添加到页面
newDiv.remove();                  // 删除自己

4.5.5 localStorage：浏览器本地存储

localStorage 可以把数据保存在用户浏览器里，关闭页面、重启电脑都不会丢失。纯前端项目保存数据的唯一方式。

// 保存（只能存字符串）
localStorage.setItem('username', '张三');

// 读取
const name = localStorage.getItem('username');

// 删除
localStorage.removeItem('username');

// 存储数组/对象（用 JSON 转换）
const todos = [{ text: '学习', done: false }];
localStorage.setItem('todos', JSON.stringify(todos));  // 存：转字符串
const saved = JSON.parse(localStorage.getItem('todos')) || [];  // 取：转数组，加默认值

localStorage 注意事项：

  • 只能存字符串，数组/对象必须用 JSON.stringify 转换
  • 第一次读取可能是 null，加 || [] 默认值
  • 存储容量约 5MB
  • 数据只存在当前浏览器，换浏览器就没了
  • 不要存敏感信息（密码等）

4.5.6 JS 常见错误

⚠️ 注意

错误1：Uncaught ReferenceError: xxx is not defined

原因：使用了没有声明的变量，或变量名拼写错误。

错误2：Cannot read properties of null (reading 'addEventListener')

原因：getElementById 没有找到元素（id 写错了，或 JS 在 HTML 元素之前执行）。

解决：检查 id；把 script 标签放在 body 末尾。

错误3：Uncaught SyntaxError: Unexpected token

原因：语法错误，少了括号、引号不配对等。看报错行号去检查。

错误4：JSON.parse 错误

原因：localStorage 中数据不是合法 JSON，或第一次是 null。加|| [] 默认值。

错误5：事件绑定了但没反应

原因：动态创建的元素，在创建前就绑定了事件。创建后立即绑定，或用事件委托。

4.6 浏览器开发者工具：你的调试利器

浏览器自带的开发者工具（DevTools）是前端开发最重要的工具。

4.6.1 打开方式

  • 快捷键：F12 或Ctrl+Shift+I（Mac:Cmd+Option+I）
  • 右键页面 → "检查"

4.6.2 常用面板

面板用途
Elements（元素）查看和修改 HTML/CSS，实时改样式看效果
Console（控制台）看红色报错、console.log 输出、直接执行 JS 代码
Sources（源代码）断点调试 JS（进阶）
Application（应用）查看/修改 localStorage 数据

4.6.3 Console 使用技巧

  • 红色文字是错误，黄色是警告。点击报错可跳转到对应代码行。
  • 在代码中加 console.log(变量名)，运行时看变量值。
  • 在控制台底部直接输入 JS 代码按回车执行，测试用。
  • Ctrl+L 清空控制台。
