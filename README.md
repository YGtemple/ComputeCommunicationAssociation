# 网络工作室 · AI小组 · 官方站点

> 「网络工作室 · AI小组」官方网站：一个同时聚焦 **AIGC（AI 生成内容）** 与 **CODING（AI 编程 / 计算机技术）** 两大方向的校园实战技术小组。内容创作与编程实践都是我们的日常，帮助新人了解小组、融入集体、获取资源、跟着讲义动手做出作品。

## 📖 项目简介

本项目是「网络工作室 · AI小组」（QQ 交流群：校园AI&计算机交流社群）的官方网站，采用纯 HTML + CSS + 少量原生 JavaScript 实现，**无需后端、无构建依赖**，可直接部署到 GitHub Pages 等任意静态托管平台。

站点为「主页 + 共享样式 + 讲义子页」的多文件结构：主页带**固定顶部导航栏**，可在任意位置快速跳转各板块并随滚动高亮当前板块，移动端为汉堡菜单；右下角配有「快速咨询 / 回到顶部」悬浮按钮。

- **AIGC** — AI 视频、短剧、动态漫、图片与内容创作
- **CODING** — Vibe Coding / AI 编程、AI 工作流与智能体、代码算法与计算机基础

## ✨ 功能亮点

- **固定导航栏** — 锚点快速跳转、滚动高亮（scrollspy）、毛玻璃效果
- **讲义多文件结构** — 章节卡片入口 + 子页连续翻页，投屏讲课友好
- **移动端适配** — 汉堡菜单，子页与表格自适应
- **悬浮快捷按钮** — 一键快速咨询 / 平滑回到顶部
- **响应式设计** — 适配桌面端与移动端
