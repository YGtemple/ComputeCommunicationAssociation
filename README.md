# ComputeCommunicationAssociation 仓库说明文档

> 一句话简介：校园AI小组官网，AIGC×CODING 与 Vibe Coding 教程

> 校园技术小组「网络工作室 · AI小组」官方站点 · 纯静态多页网站

## 一、项目概述与定位

`ComputeCommunicationAssociation` 是一个高校校园实战技术小组（对外称「网络工作室 · AI小组」）的**官方展示与教学站点**。仓库名虽直译作"计算机通信协会"，实际内容是一个聚焦 **AIGC（AI 生成内容）** 与 **CODING（AI 编程 / 计算机技术）** 两大方向的校园社团官网，并内嵌一套完整的《Vibe Coding 全流程教程》讲义。

站点特点：

- **纯静态、零后端**：纯 HTML + CSS + 少量原生 JavaScript，无框架、无构建、无依赖，可直接托管于 GitHub Pages；
- **双内容形态**：既是社团招募/介绍主页，又是一套可投屏讲课的在线讲义；
- **公益免费**：页面多处强调小组纯公益、无收费、无商业培训挂钩，面向全校各专业、零基础友好。

## 三、主页 `index.html` 内容结构

主页是一个固定顶部导航 + 长滚动单页，按锚点划分为以下板块（与导航一一对应）：

1. **封面 Header**：胶片条装饰，主标题「AIGC × CODING」，副标题「用 AI 创作视频，用自然语言编写程序」，含"立即加入/新手入门"按钮；
2. **信息条 + 入群横幅**：展示小组名称、所属学校、交流群入口（二维码图片见 `qq_qrcode.jpg`）；
3. **小组介绍（#intro）**：定位、日常节奏、适合人群、标签云；
4. **两大方向（#focus）**：左右双卡对比——AIGC（AI 视频/短剧/动态漫、文生图生视频、图像、声音后期、运营发行）与 CODING（Vibe Coding、AI 工作流与智能体、代码算法、计算机基础、竞赛备赛），下方附"日常在用工具墙"（即梦、可灵、Seedance、Runway、Midjourney、ComfyUI、扣子、HiAgent、Cursor、Trae、Codex、C/C++、Python 等）；
5. **成长路径（#path）**：时间线形式的四阶段（起步围观 → 跟练实战 → 独立产出 → 主创/负责人），每阶段分 AIGC 线与 CODING 线双列；
6. **新手指南（#guide）**：入群三步走、第一个月四周行动清单、成员福利卡片、参与建议、FAQ（六条常见问题）；
7. **我们的团队（#team）**：两位学生共同发起人卡片，分别覆盖"AI 编程/全栈开发/代码算法与 AI 工作流"与"AIGC 内容工程/AI 视频与漫剧量产"两大方向，互为补充（卡片内的个人联系方式已在本说明中按隐私要求脱敏，不复述）；
8. **日常活动（#activities）**：日常答疑 / 每周共学刷题 / 共创营·实战营 / 工作流工坊·线下沙龙；
9. **赛事与挑战（#contest）**：内部小比赛（AIGC 视频挑战、Coding 闪电赛、工作流效率赛）+ 校外正式赛事组队（黑客松、智能体赛、程序设计赛等）；
10. **福利资源（#welfare）**：对接火山引擎校园生态，提供算力扶持、技术赋能、实习通道（标注为自愿附加福利）；
11. **群规与氛围（#rules）**：人员、发言、商业、内容合规、分享、互助六条规范；
12. **加入我们（#join）**：行动号召与入群备注格式说明。

主页底部有页脚署名，以及右下角悬浮快捷按钮（"加入我们" + "回到顶部"）。

**主页交互（内联 `<script>`）**：移动端汉堡菜单开关；滚动时给导航栏加 `.scrolled` 毛玻璃样式、控制"回到顶部"按钮显隐；用 `IntersectionObserver` 做 scrollspy 高亮当前所在板块；平滑滚动回顶。

## 四、讲义子页结构（`lecture.html` 与 `lec-*.html`）

### 讲义目录页 `lecture.html`
独立入口，顶部子导航栏「🏠 返回主页」，主体是课程 Hero（标题《Vibe Coding 全流程教程》、副标题"从零开始用 AI 做出你的第一个作品·讲师投屏讲义版"、元信息"11 篇·10 章·附录 A–D"）加一个章节卡片网格。每张卡片显示徽章（第 X 章/附录 X）、章节标题、所属篇（导览篇/认知篇/工具篇/提示词工程篇/基础篇/实战篇/调试篇/部署篇/进阶篇/资源汇总篇）和页数说明；附录卡片带 `is-app` 样式区分。

### 讲义章节页模板（以 `lec-ch1.html` 为例）
所有 `lec-ch*.html` 共用同一套模板：

- **顶部子导航栏** `subpage-bar`：左「📚 讲义目录」返回 `lecture.html`，中间面包屑显示当前章标题；
- **章头** `lec-ch-head`：徽章（第 X 章）+ 章标题 + 所属篇；
- **正文区** `lec-body`：由若干 `lec-sec` 小节组成，每节有编号三级标题（如 `1.1`–`1.9`）、四级标题、段落、有序/无序列表；
- **表格** `lec-table`：大量用于对比（传统编程 vs Vibe Coding、五步循环、三层次进化模式等）；
- **色块提示** `lec-callout`：区分 `lec-warn`（⚠️ 需谨慎）、`lec-summary`（✅ 本章小结）等讲师提示/警告/小结块；
- **底部翻页** `subpage-pager`：「← 上一页 / 下一页 →」，跨章连续顺次翻阅。

### 课程内容脉络
- **第 0 章**：课程导览与学习指南；
- **第 1 章**：认识 Vibe Coding——源自 Andrej Karpathy（2025.2 提出）的 AI 编程范式，核心是"自然语言描述需求 → AI 写码 → 人验收迭代"的五步循环，辨析常见误区，介绍 Vibe/Spec/Harness 三层进化模式与 5 条实战方法论；
- **第 2 章**：6 大 AI 编程工具（Trae、豆包、WorkBuddy、GPT、DeepSeek、Grok 等）的安装与使用，共 10 个子页；
- **第 3 章**：提示词工程——如何与 AI 高效沟通；
- **第 4 章**：前端三剑客（HTML/CSS/JS）极简入门，目标是"看懂 AI 写的代码"；
- **第 5 章**：实战一——手把手做个人主页/简历页面（5 个子页）；
- **第 6 章**：实战二——做待办清单/日程助手（呼应第 1 章例子）；
- **第 7 章**：调试与排错（代码跑不起来怎么办）；
- **第 8 章**：部署上线（GitHub Pages 等）；
- **第 9 章**：进阶技巧（含 Spec Coding 思路）；
- **第 10 章**：课程总结与资源汇总；
- **附录 A–D**：分别为工具使用常见错误汇总、提示词常见错误正反例对比、前端专业术语中英文对照表、调试错误排查速查表。

## 五、技术栈与依赖

- **标记**：HTML5 语义化标签（`<section>`/`<article>`/`<header>` 等），中文 `lang="zh-CN"`；
- **样式**：`styles.css` 为唯一样式表，使用 CSS 变量（主色 `--primary:#4a6cf7`、紫色 `--accent`、粉/青/成功色等）、Flexbox/Grid、渐变、时间线、表格与 callout 样式，约 1200 行，含响应式适配；
- **交互**：原生 JavaScript，仅在 `index.html` 末尾内联一段（汉堡菜单、滚动效果、scrollspy、回顶），讲义子页基本无脚本；
- **图标**：Emoji；
- **部署**：GitHub Pages（推送 `main` 自动发布），本地预览可用任意静态服务器（如 `python -m http.server`）；
- **外部依赖**：除 README 顶部的徽章 SVG 链接（shields.io）外，站点本身不引用第三方 JS/CNS 库，完全自包含。

## 六、运行 / 使用方式

- 直接用浏览器打开 `index.html` 即可预览主页；讲义从导航栏「课程讲义」进入 `lecture.html`；
- 本地起服务：`python -m http.server 8080` 后访问 `http://localhost:8080`；
- 推送到 `main` 分支后由 GitHub Pages 自动发布为在线站点。

## 七、项目特点小结

- 一个仓库同时承载"社团招新官网"与"系统化 AI 编程入门课程"两类内容，结构清晰、职责分离（主页长滚动 / 讲义独立入口）；
- 讲义按"讲师投屏培训"场景设计，章节卡片 + 连续翻页 + 小结/警告色块 + 对比表格，教学导向明确；
- 技术实现极简（纯静态单 HTML + 共享 CSS + 少量原生 JS），便于社团成员自行修改、维护与二次发布；
- 内容面向零基础新生，强调"以战带练、作品导向、纯公益免费"。
