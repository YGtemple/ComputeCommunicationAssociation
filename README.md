# 网络工作室 · AI小组 · 新手指南

> 一个聚焦 **AIGC（AI 生成内容）** 与 **Vibe Coding（AI 编程）** 的校园技术小组官方新手指南页面，重心放在 **AIGC 视频创作**，帮助新人快速了解小组、融入集体、获取资源。

![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)

## 📖 项目简介

本项目是「网络工作室 · AI小组」（QQ 交流群：校园AI&计算机交流社群）的官方新手指南单页网站，采用纯 HTML + CSS 实现，无需后端依赖，可直接部署到任意静态托管平台。

页面以现代化的视觉设计，系统介绍小组定位、四大方向、入群流程、成员福利、团队构成、合作资源、活动安排与小组规范，是新人入群后的第一站。

## 🎯 四大方向

| 方向 | 说明 |
|------|------|
| 🎬 **AIGC 视频创作（核心重心）** | AI 文生视频 / 图生视频、AI 短剧、动态漫、AI 短片，覆盖剧本→分镜→生成→配音→剪辑→运营全流程 |
| 💻 **Vibe Coding** | 用自然语言指挥 AI 写程序，Cursor / Trae / Codex 实操，零基础做出可上线作品 |
| ⚡ **AI 工作流与智能体** | 扣子 / HiAgent / ComfyUI 工作流、AI Agent 自动化、多模型 API 批量调度 |
| 🧠 **代码 · 算法 · 计算机基础** | C / C++ / Python、数据结构与算法、刷题备赛、Git / GitHub、Linux |

## ✨ 功能亮点

- **小组介绍** — 清晰阐述小组定位与核心价值
- **四大方向卡片** — AIGC 视频核心方向重点突出，配套常用工具标签
- **入群三步走** — 改备注 → 看公告 → 自我介绍，引导新人快速融入
- **成员福利展示** — AIGC 视频实战、系统教程、答疑互助、赛事算力内推
- **团队成员介绍** — 展示核心成员的能力方向、个人优势与项目经历
- **合作资源专区** — 字节跳动 · 火山引擎算力扶持、技术赋能、实习通道
- **活动安排** — AIGC 视频共创营、Vibe Coding 实战营、工作流搭建、算法刷题、赛事沙龙
- **社群规范与 FAQ** — 明确群规氛围，解答新人常见疑问
- **响应式设计** — 适配桌面端与移动端浏览

## 🚀 快速开始

### 本地预览

直接用浏览器打开 `index.html` 即可，或使用本地服务器：

```bash
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

### 部署上线

本项目为纯静态页面，推送到 GitHub 后由 GitHub Pages 自动部署：

```bash
git add .
git commit -m "update: 聚焦 AI 小组，AIGC 视频 × Vibe Coding"
git push origin main
```
