2.3 工具二：豆包（字节跳动 · 对话式AI主力）

2.3.1 工具介绍

豆包是字节跳动推出的 AI 对话助手，类似 ChatGPT 的国产版本。它不是专门的编程工具，但因为其中文理解能力强、免费、使用门槛低，成为 Vibe Coding 中非常好用的辅助工具。

在课程中，豆包主要用于：

  • 需求梳理：把模糊的想法变成清晰的需求描述
  • 代码生成：直接让豆包写代码片段，然后复制到 Trae 中
  • 问题解答：遇到不懂的编程概念、报错信息，随时问豆包
  • 提示词优化：让豆包帮你优化给 Trae 的提示词
  • 内容创作：个人主页的文案、项目说明等，让豆包帮你写

2.3.2 使用方式

方式访问方法适合场景
网页版浏览器访问 https://www.doubao.com电脑上使用，最方便，推荐
手机 APP应用商店搜索"豆包"下载随时随地问问题、梳理思路
桌面客户端官网下载 Windows/Mac 客户端频繁使用时，不用开浏览器
小程序抖音/今日头条内搜索"豆包"不想装 APP 时临时使用

注册登录：用手机号注册即可，完全免费。免费版已经足够 Vibe Coding 使用。

2.3.3 豆包写代码的正确姿势

姿势1：直接生成代码

在对话框输入清晰的需求，豆包会直接生成代码：

帮我写一个 HTML 登录页面，要求：
1. 包含用户名输入框、密码输入框、登录按钮
2. 页面居中，简洁美观的设计风格
3. 主色调蓝色，圆角按钮
4. 点击登录按钮有简单的验证（非空检查）
5. 代码写在一个 HTML 文件中，包含 CSS 和 JS

豆包生成代码后，你可以：

  • 点击代码块右上角的"复制"按钮，复制全部代码
  • 在 Trae 中新建文件，粘贴代码
  • 保存为 .html 文件，双击用浏览器打开查看效果

姿势2：迭代修改

第一版代码不满意？继续在对话中说修改需求：

在刚才的登录页面基础上：
1. 把背景改成渐变色（从浅蓝到浅紫）
2. 输入框加图标（用户名加小人图标，密码加锁图标）
3. 登录按钮加 hover 效果（鼠标放上去变深色）
4. 加一个"忘记密码"的链接

豆包会记住上下文，在之前的代码基础上修改。

姿势3：解释和学习

刚才生成的代码里，这一段我看不懂：
【粘贴代码片段】
帮我逐行解释一下，用通俗的语言，我是零基础。

2.3.4 豆包使用技巧

  • 新建对话：不同的项目建议新建不同的对话，避免上下文混淆
  • 善用"深度思考"模式：复杂需求可以开启深度思考，回答质量更高（但速度慢一些）
  • 给参考：想要特定风格时，可以给豆包看参考图或参考代码
  • 分步骤：复杂需求不要一次全说，先搭框架，再逐步加功能
  • 让它自检：代码生成后，可以说"检查一下这段代码有没有 bug 或可以优化的地方"
  • 用"继续"补全：如果豆包回答到一半断了，输入"继续"，它会接着写

2.4 工具三：DeepSeek（国产开源 · 代码能力强）

2.4.1 工具介绍

DeepSeek是国内深度求索公司推出的开源大语言模型，以代码能力强、推理能力强、完全开源、免费使用著称。在编程任务上，DeepSeek 经常能媲美甚至超过 GPT-4，是 Vibe Coding 的强力备选工具。

DeepSeek 的优势：

  • 代码能力强：DeepSeek Coder 是专门针对代码优化的模型
  • 推理能力强：DeepSeek R1 推理模型，复杂逻辑处理好
  • 完全免费：网页版免费使用，API 价格极低
  • 开源：模型开源，可以本地部署（需要好显卡）
  • 长上下文：支持长文本，大项目也能处理

2.4.2 使用方式

网页版（最简单，推荐）

  1. 浏览器访问：https://chat.deepseek.com
  2. 用手机号注册登录
  3. 直接在对话框输入需求，和豆包用法一样
  4. 可以在顶部切换模型：DeepSeek V3（通用）或 DeepSeek R1（推理）

API 接入（进阶）

如果你想在 Trae、Cursor 等工具中使用 DeepSeek 模型，可以通过 API 接入：

  1. 访问 DeepSeek 开放平台：https://platform.deepseek.com
  2. 注册登录，在左侧菜单找到"API Keys"
  3. 点击"创建新的 API Key"，复制保存好（只显示一次）
  4. 在 Trae/Cursor 的模型设置中，选择自定义模型，填入：
    • API 地址：https://api.deepseek.com
    • API Key：你刚才复制的 key
    • 模型名：deepseek-chat 或 deepseek-reasoner
📌 补充
关于 API 费用：DeepSeek API 价格非常便宜，输入约 1 元/百万 token，输出约 2 元/百万 token。做几个小项目可能几毛钱都花不到。新用户注册还会送免费额度。学生完全负担得起。

2.4.3 DeepSeek 写代码技巧

  • 用 R1 模型处理复杂逻辑：涉及算法、复杂业务逻辑时，切换到 R1 推理模型，质量更高
  • 用 V3 模型做日常开发：普通页面生成、样式调整，用 V3 速度更快
  • 让它先思考再回答：可以在提示词开头加"请先思考，然后给出答案"，提升质量
  • 代码审查："请审查这段代码，找出潜在的 bug、安全问题和性能问题"
  • 分步实现：复杂项目让 DeepSeek 先给出实现计划，确认后再分步写代码

2.5 工具四：WorkBuddy（腾讯出品 · 备选工具）

2.5.1 工具介绍

WorkBuddy（曾用名 CodeBuddy）是腾讯云推出的 AI 编程助手，有两种形态：IDE 插件版和独立客户端版。

WorkBuddy 的特点：

  • 腾讯出品，对中文需求理解好
  • 多模式：Craft（生成模式）、Plan（计划模式）、Chat（对话模式）
  • 免费额度：有免费使用额度，对学生友好
  • 腾讯生态集成：和腾讯云、微信小程序等生态结合好

2.5.2 安装与使用

独立客户端（推荐新手）

  1. 访问 WorkBuddy 官网：https://codebuddy.tencent.com
  2. 下载对应系统的安装包
  3. 安装后用微信或腾讯云账号登录
  4. 界面和 Trae 类似，左侧文件、中间编辑、右侧 AI 对话

VS Code 插件（有基础的同学）

  1. 打开 VS Code，按 Ctrl+Shift+X 打开扩展市场
  2. 搜索"WorkBuddy"或"Tencent Cloud AI"
  3. 点击安装，安装完成后重启 VS Code
  4. 点击左侧活动栏的 WorkBuddy 图标，登录账号即可使用

2.5.3 三种模式详解

模式用途适合场景
Craft（生成模式）AI 自动生成完整项目或功能从零开始做新项目、生成完整页面
Plan（计划模式）AI 先给出修改计划，确认后再执行修改已有项目、复杂功能开发，避免 AI 乱改
Chat（对话模式）问答、解释、讨论问问题、解释代码、梳理思路
💡 讲师提示
新手建议：先用 Craft 模式快速生成初版，然后用 Chat 模式逐步调整。Plan 模式适合项目变大后、需要谨慎修改时使用。

2.6 工具五：GPT / ChatGPT（OpenAI · 国际主流）

2.6.1 工具介绍

ChatGPT是 OpenAI 推出的 AI 对话助手，是目前全球最知名的 AI 工具。GPT-4o、GPT-4o-mini 等模型在代码生成方面能力很强。

在课程中，GPT 作为备选工具使用：

  • 当国产工具生成的代码不满意时，可以用 GPT 试试
  • 复杂的算法、架构问题，GPT 处理能力强
  • 英文资料、国际开源项目相关问题，GPT 更有优势

2.6.2 使用方式

方式说明费用
网页版访问 https://chat.openai.com，注册账号免费版可用 GPT-4o-mini；Plus 订阅 $20/月可用 GPT-4o
手机 APPApp Store / Google Play 搜索"ChatGPT"同网页版
桌面客户端官网下载 Windows/Mac 客户端同网页版
⚠️ 注意
注意：ChatGPT 在国内访问需要特殊网络条件。如果无法访问，不用担心，课程中的所有任务用 Trae + 豆包 + DeepSeek 都能完成。GPT 只是备选，不是必须。

2.7 工具六：Grok（xAI · 可选参考）

Grok是埃隆·马斯克的 xAI 公司推出的 AI 助手，以"性格鲜明、实时信息、幽默风趣"著称。Grok 在编程方面也有不错的能力。

在课程中，Grok 作为可选参考工具：

  • 偶尔用来对比不同 AI 的代码生成结果
  • 需要实时搜索最新技术文档时
  • 换个 AI 的思路解决棘手问题

使用方式：访问 https://grok.com 或下载手机 APP，需要 X（Twitter）账号登录。免费版有使用限制，Premium+ 订阅解锁完整功能。国内访问需要特殊网络条件。

💡 讲师提示
课程建议：Grok 不是必须的工具。如果你能访问并且有订阅，可以偶尔用用；如果没有，完全不影响学习。把精力放在 Trae + 豆包 + DeepSeek 这三个有 generous 免费额度、中文友好的工具上就够了。

2.8 工具选择与组合策略

2.8.1 新手推荐组合

零基础新手最佳组合（均有免费版，轻度使用零成本）：

  • 主力 IDE：Trae（写项目、改代码）
  • 对话助手：豆包（问问题、梳理需求、写文案）
  • 代码加强：DeepSeek（复杂逻辑、代码审查）

这三个工具都有 generous 的免费额度（Trae 每月500积分+签到、豆包基础对话不限次、DeepSeek 网页版完全免费），中文友好，足够你完成课程中的所有项目。

2.8.2 不同场景的工具选择

场景推荐工具原因
从零做新项目Trae（Builder模式）AI 原生 IDE，自动创建文件，体验最流畅
生成代码片段豆包 / DeepSeek对话式，生成后复制粘贴，简单直接
修改已有代码Trae（Builder/Chat）直接在项目中修改，上下文完整
解释代码/学概念豆包 / DeepSeek中文解释通俗易懂
复杂算法/逻辑DeepSeek R1 / GPT-4o推理能力强，复杂问题处理好
代码审查/找bugDeepSeek / GPT-4o代码分析能力强，找问题准
写文案/项目说明豆包中文创作能力强
根据设计图写页面Trae / GPT-4o多模态支持，能看图写代码

2.8.3 多模型组合使用技巧

  1. 不要在一个工具上死磕：一个工具生成的代码不满意，换个工具试试，可能效果完全不同
  2. 用 A 工具生成，B 工具审查：比如用 Trae 生成代码，然后把代码贴给 DeepSeek 让它审查找 bug
  3. 用对话工具梳理需求，再用 IDE 实现：先在豆包里把需求聊清楚、梳理成结构化的需求文档，再拿到 Trae 里实现
  4. 建立自己的工具偏好：用多了你会发现不同工具的特点，形成自己的组合习惯

2.10 全球主流 AI 编程工具全景图（优缺点与使用限制）

前面我们详细介绍了课程主力使用的 6 个工具（Trae、豆包、DeepSeek、WorkBuddy、GPT、Grok）。但全球 AI 编程工具远不止这些。本节带你全景了解全球各类主流 AI 编程工具，详细分析每个工具的优点、缺点、使用限制、价格和国内可用性，帮你根据自己的需求做出选择。

工具分类说明：全球 AI 编程工具按形态可分为六大类——AI 原生 IDE、IDE 插件、终端/CLI 工具、开源可自托管工具、国产工具、AI 软件工程师（SaaS Agent）。不同形态适合不同人群和场景。

2.10.1 第一类：AI 原生 IDE（独立编辑器）

AI 原生 IDE 是基于 VS Code 或其他编辑器深度定制、从底层为 AI 编程设计的独立开发环境。它们不是插件，而是完整的编辑器，AI 功能深度集成。
