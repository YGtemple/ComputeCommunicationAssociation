前端三剑客极简入门 —— 看懂AI写的代码

第五篇 · 基础篇

4.1 为什么要学"看懂代码"

很多同学会问："Vibe Coding 不是 AI 写代码吗？我为什么还要学代码？"

问得好。Vibe Coding 确实不需要你手写代码，但你至少需要能看懂代码。就像你不需要会开车，但至少要能看懂导航、知道车在往哪走、出了问题大概是哪里坏了。

本章目标：不是让你成为程序员，而是让你达到三个能力：

  1. 能看懂：AI 生成的代码，你能大概知道每部分在干什么
  2. 能定位：出了问题，你能大概判断是 HTML 结构问题、CSS 样式问题，还是 JS 逻辑问题
  3. 能沟通：和 AI 描述问题时，你能用准确的术语（比如"div 标签"、"class 属性"、"click 事件"），而不是"那个东西"、"那个框"

4.2 网页是怎么来的：三剑客的分工

一个网页，本质上是由三种"语言"共同构成的，我们称之为前端三剑客：

语言全称负责什么类比例子
HTMLHyperText Markup Language（超文本标记语言）网页的结构和内容：有什么元素、元素之间什么关系盖房子的骨架：哪里是墙、哪里是门、哪里是窗户标题、段落、按钮、输入框、图片
CSSCascading Style Sheets（层叠样式表）网页的样式和外观：长什么样、什么颜色、多大、在哪房子的装修：墙刷什么颜色、地板用什么材质、灯装什么样颜色、字体、大小、间距、圆角、阴影、动画
JavaScriptJavaScript（简称 JS）网页的行为和交互：用户操作时发生什么房子的水电和智能设备：按开关灯亮、开门空调自动开点击按钮弹出提示、输入内容实时搜索、表单验证

一句话记忆：HTML 是骨架（有什么），CSS 是皮肤（长什么样），JS 是肌肉（能干什么）。三者配合，才是一个完整的网页。

一个最简单的网页例子

让我们看一个最简单的网页，感受三剑客如何配合：

<!DOCTYPE html>
<html>
<head>
  <title>我的第一个网页</title>
  <style>
    /* 这是 CSS：控制样式 */
    h1 {
      color: blue;        /* 标题颜色：蓝色 */
      text-align: center;  /* 标题居中 */
    }
    button {
      background-color: green;  /* 按钮背景：绿色 */
      color: white;              /* 按钮文字：白色 */
      padding: 10px 20px;       /* 按钮内边距 */
      border-radius: 5px;        /* 圆角 */
    }
  </style>
</head>
<body>
  <!-- 这是 HTML：结构和内容 -->
  <h1>欢迎来到我的网页！</h1>
  <p>这是一个段落文字。</p>
  <button id="myButton">点我一下</button>

  <script>
    // 这是 JavaScript：行为和交互
    document.getElementById('myButton').addEventListener('click', function() {
      alert('你点击了按钮！');  // 点击按钮时弹出提示
    });
  </script>
</body>
</html>

这个网页中：

  • HTML（body 部分）：定义了一个标题、一个段落、一个按钮
  • CSS（style 标签里）：让标题变成蓝色居中，按钮变成绿色圆角白字
  • JS（script 标签里）：让按钮被点击时弹出"你点击了按钮！"

4.3 HTML：网页的骨架

4.3.1 什么是标签

HTML 由一个个标签（Tag）组成。标签用尖括号括起来，通常是成对出现的：

<标签名>内容</标签名>

例如：
<h1>这是一级标题</h1>
<p>这是一个段落</p>
<button>这是一个按钮</button>
  • <h1> 是开始标签，表示从这里开始是标题
  • </h1> 是结束标签（多了一个斜杠），表示标题到这里结束
  • 中间的文字是内容

有些标签没有结束标签，叫做自闭合标签，比如图片：

<img src="图片地址" alt="图片描述">

4.3.2 什么是属性

标签可以有属性（Attribute），用来给标签添加额外信息。属性写在开始标签里：

<标签名 属性名="属性值">内容</标签名>

例如：
<a href="https://www.baidu.com" target="_blank">百度链接</a>
<img src="photo.jpg" alt="我的照片" width="200">
<button id="submitBtn" class="btn-primary">提交</button>

常见属性：

  • id：给元素一个唯一的名字，JS 用来找到它（比如id="myButton"）
  • class：给元素分类，CSS 用来批量设置样式（比如class="card"）
  • src：资源地址（图片、脚本等）
  • href：链接地址
  • alt：图片描述（图片加载失败时显示，也给盲人读屏软件用）

4.3.3 常用标签速查表

标签名称用途例子
<h1> ~ <h6>标题标题，h1最大，h6最小<h1>大标题</h1>
<p>段落一段文字<p>这是一段话</p>
<a>链接可点击的超链接<a href="url">点我</a>
<img>图片显示图片<img src="a.jpg" alt="图">
<button>按钮可点击的按钮<button>确定</button>
<input>输入框文本输入、复选框等<input type="text" placeholder="请输入">
<div>区块最常用的容器，用来分组<div>一组内容</div>
<span>行内容器对文字中的一部分设置样式<span style="color:red">红色</span>
<ul> / <li>无序列表带圆点的列表<ul><li>项目1</li></ul>
<ol> / <li>有序列表带数字的列表<ol><li>第一步</li></ol>
<form>表单包含输入框、按钮的提交区域<form>...</form>
<header>页眉页面顶部区域（语义化）<header>导航栏</header>
<footer>页脚页面底部区域（语义化）<footer>版权信息</footer>
<nav>导航导航链接区域（语义化）<nav>菜单</nav>
<section>区块一个独立的内容区块（语义化）<section>关于我</section>

语义化标签：header、footer、nav、section 这些标签叫"语义化标签"，它们本质上和 div 一样（都是容器），但名字有意义，让人和 AI 都能一眼看懂这个区域是干什么的。写代码时优先用语义化标签。

4.3.4 HTML 的基本结构

每个 HTML 文件都有一个固定的基本结构：

<!DOCTYPE html>              <!-- 声明：这是一个 HTML5 文档 -->
<html>                       <!-- 根标签：整个网页从这里开始 -->
  <head>                     <!-- 头部：网页的元信息（不在页面上显示） -->
    <meta charset="UTF-8">   <!-- 字符编码：告诉浏览器用 UTF-8 解码 -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">  <!-- 响应式：让手机端正常显示 -->
    <title>网页标题</title>   <!-- 网页标题：显示在浏览器标签页上 -->
    <style>                  <!-- CSS 样式写在这里 -->
      /* CSS 代码 */
    </style>
  </head>
  <body>                     <!-- 主体：网页上显示的内容都在这里 -->
    <!-- 页面内容：标题、段落、按钮、图片等 -->
    <script>                 <!-- JavaScript 写在这里（通常放在 body 末尾） -->
      // JS 代码
    </script>
  </body>
</html>

记住：用户能看到的内容都在<body> 里；<head> 里是配置信息，用户看不到（除了 title 显示在标签页上）。

4.3.5 HTML 常见错误

⚠️ 注意

错误1：标签没有闭合

<div>内容（少了</div>）→ 会导致后面的元素布局错乱

错误2：标签嵌套错误

<div><p>文字</div></p>（交叉嵌套）→ 正确应该是<div><p>文字</p></div>

错误3：属性值没有加引号

<div class=box> → 正确应该是<div class="box">

错误4：id 重复

同一个页面中两个元素用了相同的 id → JS 找元素时会混乱。id 必须唯一，重复的用 class。

4.4 CSS：网页的皮肤

4.4.1 CSS 的基本语法

CSS 由一条条规则组成，每条规则告诉浏览器"哪个元素要变成什么样"：

选择器 {
  属性名: 属性值;
  属性名: 属性值;
}

例如：
h1 {
  color: blue;
  font-size: 24px;
  text-align: center;
}
  • 选择器（Selector）：选中要设置样式的元素（上面的h1 表示选中所有一级标题）
  • 属性（Property）：要设置什么样式（color 是颜色，font-size 是字号）
  • 值（Value）：具体设置成什么（blue 是蓝色，24px 是24像素）
  • 每条声明以分号 ; 结尾

4.4.2 三种写 CSS 的方式

方式写法优点缺点适用场景
内联样式写在 HTML 标签的 style 属性里：<div style="color:red">优先级最高，直接生效代码混乱，不能复用，难维护临时改一个元素的样式，不推荐常用
内部样式表写在 HTML 的 <style> 标签里和 HTML 在一个文件，方便只能作用于当前页面单文件小项目（本课程的项目都用这种）
外部样式表写在单独的 .css 文件中，用 <link> 引入可复用于多个页面，结构清晰多一个文件，需要管理多页面的正式项目

本课程的项目都是单文件（HTML/CSS/JS 都写在一个 .html 文件里），所以用内部样式表（<style> 标签）。

4.4.3 常用选择器

选择器写法选中什么例子
元素选择器标签名所有该标签的元素p { color: red; } 所有段落变红
ID 选择器#id名id 等于该值的元素（唯一）#header { background: blue; }
类选择器.类名class 包含该值的所有元素.card { border: 1px solid #ccc; }
后代选择器父 子父元素里面的所有子元素（包括深层）.header .nav a { ... }
伪类选择器元素:状态特定状态下的元素button:hover { ... } 鼠标悬停时
群组选择器A, B, C同时选中多个元素h1, h2, h3 { font-family: sans-serif; }

最常用的伪类：

  • :hover：鼠标悬停时（按钮变颜色、卡片放大等）
  • :active：鼠标按下时
  • :focus：获得焦点时（输入框被点击时）
  • :nth-child(n)：第 n 个子元素（列表隔行变色）
