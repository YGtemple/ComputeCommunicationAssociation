部署上线 —— 让全世界看到你的作品

第九篇 · 部署篇

8.1 为什么要部署

你花了好几个小时做的个人主页和待办清单，现在只能在你自己的电脑上打开。怎么让你的朋友、同学、面试官也能看到？答案是：部署上线。

部署就是把你的代码文件放到一个永远在线的服务器上，这样任何人在任何地方，只要输入网址就能访问你的网站。

部署后你能得到什么：

  • 一个专属网址（如 https://你的名字.github.io/portfolio）
  • 任何人都能通过网址访问你的作品
  • 可以把网址放在简历、社交媒体、邮件签名里
  • 面试时直接打开网址展示作品，比说"我做过XX"有说服力 100 倍

8.2 部署前的准备

8.2.1 确认你的项目是静态网站

本课程的两个项目（个人主页、待办清单）都是静态网站——只有 HTML/CSS/JS 文件，不需要服务器后端、不需要数据库。静态网站可以用免费的静态托管服务部署。

确认你的项目：

  • 只有 .html、.css、.js 文件（本课程项目都写在一个 .html 文件里）
  • 没有用到 PHP、Python、Node.js 等后端语言
  • 没有用到 MySQL、MongoDB 等数据库
  • 数据存在浏览器 localStorage 里（待办清单）

如果符合以上条件，就可以用下面介绍的免费服务部署。

8.2.2 部署前检查清单

检查项说明
首页文件名是 index.html服务器默认找 index.html 作为首页，如果文件名不对会 404
所有文件在同一个文件夹HTML、CSS、JS、图片都在项目文件夹里，路径正确
图片用相对路径用 src="avatar.jpg" 而不是src="C:\Users\xxx\avatar.jpg"
本地测试正常双击 index.html 能正常打开，所有功能正常
控制台无红色报错F12 打开控制台，确认没有红色错误
没有敏感信息代码中没有写密码、密钥、手机号等敏感信息

8.3 方式一：Netlify 拖拽部署（最简单，推荐新手）

Netlify 是一个静态网站托管服务，最大的优点是可以直接拖拽文件夹部署，不需要装 Git、不需要敲命令，5 分钟就能搞定。

8.3.1 注册 Netlify 账号

  1. 打开浏览器，访问 https://www.netlify.com
  2. 点击右上角"Sign up"注册
  3. 推荐用 GitHub 账号登录（如果有 GitHub 账号的话），或者用邮箱注册
  4. 注册后登录，进入 Netlify 控制台

8.3.2 拖拽部署

  1. 在 Netlify 控制台，找到"Deploy manually"或"Sites"页面
  2. 你会看到一个写着"Drag and drop your site output folder here"的区域
  3. 打开你的项目文件夹，把整个文件夹（包含 index.html 的那个文件夹）直接拖拽到这个区域
  4. 等待上传完成（几秒钟到几分钟，取决于文件大小）
  5. 上传完成后，Netlify 会自动给你一个网址，格式如：https://random-name-12345.netlify.app
  6. 点击这个网址，你的网站就上线了！
⚠️ 注意
拖拽的是文件夹，不是单个 index.html 文件。确保文件夹里有 index.html。如果拖拽后网站显示 404，检查一下 index.html 是否在文件夹根目录（不是在子文件夹里）。

8.3.3 修改网站名称

Netlify 给的随机网址不好记，你可以改成自定义名称：

  1. 在 Netlify 控制台点击你的网站
  2. 点击"Site settings"（站点设置）
  3. 找到"Site name"，点击"Change site name"
  4. 输入你想要的名称（如 wangjiaqi-portfolio），保存
  5. 你的网址就变成了：https://wangjiaqi-portfolio.netlify.app

注意：名称不能和别人重复，如果提示已被占用，换一个。

8.3.4 更新网站

你改了代码后，需要重新部署：

  1. 在 Netlify 控制台点击你的网站
  2. 点击"Deploys"标签
  3. 找到"Drag and drop"区域，把更新后的文件夹再次拖拽进去
  4. 等待上传完成，网站就自动更新了

或者，如果你绑定了 GitHub 仓库（见下文），每次 push 代码会自动部署，更方便。

8.4 方式二：GitHub Pages（适合想学习 Git 的同学）

GitHub Pages 是 GitHub 提供的免费静态网站托管服务。优点是和代码管理结合在一起，更新代码自动部署；缺点是需要先学一点 Git 基础知识。

8.4.1 注册 GitHub 账号

  1. 访问 https://github.com
  2. 点击"Sign up"注册
  3. 输入用户名（这个名字会出现在你的网址里，建议用英文名或拼音）、邮箱、密码
  4. 完成验证，注册成功
  5. 登录后，你可以在 https://github.com/你的用户名 看到你的主页

8.4.2 创建代码仓库

  1. 登录 GitHub，点击右上角 "+" → "New repository"
  2. Repository name（仓库名）：输入项目名称，如 portfolio 或todo-list
  3. Description（描述）：可选，简单写一句，如"我的个人主页"
  4. 选择 Public（公开，免费）
  5. 勾选"Add a README file"（可选）
  6. 点击"Create repository"

8.4.3 上传代码文件

有两种方式上传代码：网页上传（简单）和 Git 命令上传（专业）。

方式 A：网页上传（新手推荐）

  1. 进入刚创建的仓库页面
  2. 点击"Add file" → "Upload files"
  3. 把你的项目文件（index.html 以及图片等）拖拽到上传区域
  4. 等待上传完成
  5. 点击底部"Commit changes"提交
  6. 文件就上传到 GitHub 了

方式 B：Git 命令上传（推荐学习）

如果你想学习 Git，先安装 Git（https://git-scm.com/downloads），然后：

# 1. 进入项目文件夹
cd 你的项目文件夹路径

# 2. 初始化 Git 仓库
git init

# 3. 添加所有文件
git add .

# 4. 提交（写一句提交说明）
git commit -m "初始版本：个人主页"

# 5. 关联 GitHub 远程仓库（把下面的 URL 换成你自己的仓库地址）
git remote add origin https://github.com/你的用户名/仓库名.git

# 6. 推送到 GitHub
git push -u origin main

第一次 push 会要求输入 GitHub 用户名和密码（现在用 Personal Access Token 代替密码，在 GitHub 设置里生成）。

8.4.4 开启 GitHub Pages

  1. 进入你的仓库页面
  2. 点击"Settings"（设置）
  3. 左侧菜单找到"Pages"
  4. 在"Build and deployment"下，Source 选择"Deploy from a branch"
  5. Branch 选择"main"，文件夹选择"/(root)"
  6. 点击"Save"
  7. 等待 1-2 分钟，刷新页面，顶部会显示你的网站地址：https://你的用户名.github.io/仓库名/
  8. 点击这个地址，你的网站就上线了！
⚠️ 注意

GitHub Pages 的网址格式是https://用户名.github.io/仓库名/，不是根域名。如果你的网站中有绝对路径（如src="/avatar.jpg"），可能会 404。建议全部用相对路径（src="avatar.jpg"）。

如果想要 https://用户名.github.io/ 这种根域名，需要把仓库命名为你的用户名.github.io。

8.4.5 更新网站

改了代码后：

  • 网页上传：重新到仓库页面，上传修改后的文件，覆盖旧文件，commit 后自动更新
  • Git 命令：git add . →git commit -m "修改说明" →git push，push 后自动部署

GitHub Pages 部署需要 1-2 分钟，刷新网址就能看到更新。

8.6 部署后检查与常见问题

8.6.1 部署后检查清单

  1. 网址能正常打开，不显示 404
  2. 页面样式正常（CSS 加载成功）
  3. 所有功能正常（按钮点击、表单提交等）
  4. 图片正常显示（没有裂图）
  5. 手机端打开正常（用手机访问试试）
  6. 控制台无红色报错（F12 查看）
  7. 刷新页面后数据不丢失（待办清单的 localStorage）

8.6.2 常见问题

问题1：打开网址显示 404 Not Found
原因：index.html 不在根目录，或者文件名不对（比如是 home.html 而不是 index.html）。
解决：确保项目根目录有 index.html 文件。GitHub Pages 还要确认 Pages 设置中选对了分支和文件夹。
问题2：页面显示了但没有样式（纯文字，像 90 年代网页）
原因：CSS 文件路径不对，或者 CSS 写在 style 标签里但被误删了。
解决：本课程项目 CSS 都写在 HTML 的 style 标签里，应该不会有这个问题。如果是外部 CSS 文件，检查路径是否正确（用相对路径）。
问题3：图片不显示（裂图）
原因：图片路径不对，或者图片没有上传，或者用了本地绝对路径（C:\Users\xxx...）。
解决：图片和 HTML 放在同一个文件夹，用相对路径src="avatar.jpg"。确认图片已经上传到 GitHub/Netlify。
问题4：GitHub Pages 网址一直 404，等了很久也不生效
原因：Pages 设置不对，或者仓库是 Private（私有仓库的 Pages 需要付费）。
解决：确认仓库是 Public，Settings → Pages 中 Source 选了正确的分支（main）和文件夹（root）。如果刚设置，等 2-3 分钟再刷新。
问题5：更新代码后网址没有变化
原因：浏览器缓存了旧版本，或者部署还没完成。
解决：按 Ctrl+Shift+R 强制刷新。GitHub Pages 等 1-2 分钟。Netlify 拖拽后立即生效。
问题6：待办清单的数据在不同电脑上不同步
原因：localStorage 是存在每个浏览器本地的，换电脑或换浏览器数据就不一样了。这是正常的，纯前端项目就是这样。
解决：如果需要多设备同步，需要后端和数据库（超出本课程范围）。对于个人使用，在常用浏览器上用就好。

8.7 自定义域名（可选，进阶）

如果你想要一个专属域名（如 www.wangjiaqi.com），可以购买域名并绑定到 Netlify 或 GitHub Pages：

  1. 在域名服务商（如阿里云、腾讯云、GoDaddy、Namecheap）购买一个域名（约 30-100 元/年）
  2. 在 Netlify：Site settings → Domain management → Add custom domain，输入你的域名，按提示在域名服务商处设置 DNS 解析
  3. 在 GitHub Pages：Settings → Pages → Custom domain，输入域名，同时在域名服务商设置 CNAME 解析
  4. 等待 DNS 生效（几分钟到几小时），HTTPS 证书会自动签发

这一步是可选的，新手用免费的 netlify.app 或 github.io 域名就足够了。等你以后有需要再绑定自定义域名。

✅ 本章小结

本章关键点：

  1. 部署让你的作品被全世界看到：把代码放到永远在线的服务器，任何人输入网址就能访问。
  2. 部署前检查：index.html 在根目录、相对路径、本地测试正常、无红色报错、无敏感信息。
  3. Netlify 拖拽部署（新手首选）：注册账号 → 拖拽文件夹 → 获得网址 → 修改站点名称。5 分钟搞定，不需要学 Git。
  4. GitHub Pages（推荐学习）：注册 GitHub → 创建仓库 → 上传代码 → Settings → Pages 开启。网址格式 https://用户名.github.io/仓库名/。
  5. 更新网站：Netlify 重新拖拽；GitHub 重新上传或 git push。
  6. 常见问题：404（检查 index.html）、无样式（检查 CSS 路径）、图片裂（检查相对路径）、不更新（强制刷新+等部署）。
  7. 自定义域名可选：新手用免费域名就够，以后需要再买域名绑定。
  8. 部署是最好的激励：把你的作品链接发到社群、朋友圈、简历里，看到别人访问和点赞，会给你巨大的成就感，激励你继续学习。
