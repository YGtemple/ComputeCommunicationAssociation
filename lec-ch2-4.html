维度详情
开发方Paul Gauthier（开源项目，GitHub 44K+ Star）
产品形态终端 CLI 工具，pip 安装，支持任何编辑器
核心功能终端内 AI 结对编程、自动 Git 提交（每次修改自动 commit）、支持 100+ 模型、Architect 模式（双模型分工：一个想一个写）、Token 消耗最低、支持本地模型（Ollama）

6.支持本地模型：配合 Ollama 可完全离线使用，代码不出本机

3.需要自己配 API Key：不像订阅制工具开箱即用，需要自己去各平台申请 API
4.社区和文档偏英文：中文资料较少
5.没有内置预览和调试：需要自己配合编辑器使用
💰 价格软件本身：完全免费开源
API 费用：按实际调用计费，用 DeepSeek 等便宜模型成本极低（几元/月），用 GPT-4o/Claude 成本较高
🇨🇳 国内可用性✅ 软件本身开源可下载。配合 DeepSeek 等国内可访问的 API，国内可正常使用。配合 GPT/Claude 需特殊网络。
👤 适合人群终端控、预算紧的学生/个人开发者、多模型切换党、注重隐私想用本地模型的人、有一定命令行基础的人。

2.10.4 第四类：开源可自托管工具（数据完全自己掌控）

开源可自托管工具的核心理念是：代码完全开源，模型自己选（可接第三方 API，也可接本地模型），数据完全自己掌控。它们通常以 VS Code 插件形式存在，适合注重隐私、想自由组合模型、预算有限的开发者。

工具10：Cline —— 增长最快的开源 AI 编程智能体

维度详情
开发方开源社区（原 Claude Dev，后改名 Cline），GitHub 500 万+ 开发者使用
产品形态VS Code 插件（开源，Apache 2.0 协议）
核心功能Plan/Act 双模式（先分析再执行 / 直接干活）、自动读写文件、执行终端命令、浏览器操作、支持任意 OpenAI 兼容 API（GPT、Claude、Gemini、DeepSeek、本地 Ollama 等）、每次文件修改和命令需用户审批（人在回路）、diff 预览
✅ 优点1. 完全开源免费：软件本身不收费，只付 API 费用
2.模型自由：支持任意 OpenAI 兼容 API，可接 DeepSeek（极便宜）、本地 Ollama（完全免费）等
3.人在回路控制：每次文件修改和终端命令都需你审批，安全可控
4.Plan/Act 双模式：复杂任务先规划再执行，简单任务直接干
5.增长势头猛：500 万+ 开发者使用，社区活跃
6.可接本地模型：配合 Ollama 完全离线，代码不出本机
❌ 缺点与限制1. 偏极客向：新手上手有一定门槛，需要配置 API、理解各种设置
2.需要自己配 API Key：不像订阅制工具开箱即用
3.每次操作需审批：安全但繁琐，长任务需要频繁点确认
4.重写整个文件：修改时重写整个文件，消耗更多输出 token（Roo Code 改进了这点）
5.中文资料相对少：主要靠英文文档和社区
6.产品稳定性：开源项目，偶有 bug
💰 价格软件：完全免费开源
API：按实际调用计费，用 DeepSeek 成本极低（几元/月），用 GPT-4o/Claude 成本较高
🇨🇳 国内可用性✅ 插件可在 VS Code 市场直接下载。配合 DeepSeek 等国内 API 可正常使用。配合 GPT/Claude 需特殊网络。
👤 适合人群需要灵活性和定制化的开发者、多模型实验者、预算有限的学生、注重隐私想用本地模型的人、有一定技术能力的人。不适合纯零基础新手。

工具11：Roo Code —— Cline 的增强分支，更省 token

维度详情
开发方Qodo（基于 Cline 开源代码 fork 的增强版本）
产品形态VS Code 插件（开源）
核心功能在 Cline 基础上增强：diff-based 编辑（只输出修改的行，更省 token）、更细致的提示词设置（输出语言、提示词增强、不同角色）、编码/架构优化/提问等角色模式、clinerules 细粒度权限控制
✅ 优点1. diff-based 编辑更省 token：500 行文件只改 10 行时，比 Cline 全文件重写省约 30% 成本
2.提示词设置更细致：可设置输出语言、提示词增强、不同角色模式
3.细粒度权限控制：clinerules 可定义 AI 能碰哪些目录、调用哪些工具、哪些操作需审批
4.企业级功能：SSO、RBAC、SOC 2/GDPR 合规
5. 开源免费，模型自由
❌ 缺点与限制1. 不支持 Ollama 本地模型（相比 Cline 的一个劣势）
2. 同样偏极客向，新手有门槛
3. 高级功能（企业版）需付费
4. 社区规模不如 Cline 大
5. 文档和资料英文为主
💰 价格个人版：免费开源
企业版：定制报价（SSO、RBAC、合规等）
API 费用：按实际调用计费
🇨🇳 国内可用性✅ 同 Cline，插件可直接下载，配合国内 API 可用。
👤 适合人群在 Cline 基础上想要更省 token、更细致控制的开发者、企业团队（合规需求）。

Enterprise：定制报价

👤 适合人群喜欢折腾和定制的开发者、团队（构建专属 AI Agent）、JetBrains 用户、想用本地模型的人。
