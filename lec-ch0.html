0.1 欢迎来到 Vibe Coding 的世界

你好，同学！欢迎加入 校园AI&计算机交流社群 的 Vibe Coding 全流程教程。

这门课专为完全零基础的同学设计——你不需要懂任何编程语言，不需要会装复杂的开发环境，甚至不需要知道"代码"长什么样。你只需要会用浏览器、会打字、会用中文描述你想要什么，就能在课程结束时做出两个可以上线分享的真实作品：一个个人主页/简历网站，和一个待办清单/日程助手。

一句话理解 Vibe Coding：你用自然语言说出想法，AI 帮你写代码，你负责验收和提修改意见。就像跟一个随叫随到的程序员搭档合作，你是产品经理，它是码农。

0.5 学习建议

建议1：边看边动手，不要只看不动

Vibe Coding 是一门实践课，看10遍不如亲手做1遍。每个章节都跟着视频一起操作，遇到问题暂停视频自己先试一下，再继续看。

建议2：接受"不完美"，先跑起来再说

新手最大的障碍是追求完美。Vibe Coding 的核心理念是"先让它能跑，再慢慢优化"。第一版丑没关系、有bug没关系，能运行就是胜利。

建议3：报错是常态，不是你笨

即使是专业程序员，每天也会遇到大量报错。AI 生成的代码出问题太正常了。遇到报错 = 学习机会，跟着第7章的方法一步步排查，你会越来越熟练。

建议4：建立自己的提示词库和错题本

课程中会给出很多好用的提示词模板。建议你准备一个文档，把好用的提示词、踩过的坑、解决方法都记录下来。这会成为你最宝贵的资产。

建议5：加入社群，互相帮助

一个人学容易卡住，一群人学进步更快。加入我们的 QQ群 926936791，遇到问题在群里问，会有学长学姐和同学帮你解答。也欢迎你学会后帮助其他新手——教是最好的学。

0.7 常见问题 FAQ

Q：我完全不会编程，真的能学会吗？
A：完全可以。这门课就是为零基础设计的。Vibe Coding 不需要你手写代码，只需要你会用中文描述需求。跟着课程一步步做，就能做出作品。
Q：需要花钱买工具吗？
A：不需要。课程主力工具都有 generous 免费额度（Trae 每月500积分+签到、豆包基础对话不限次、DeepSeek 网页版完全免费），GitHub Pages 和 Netlify 部署也免费。
Q：我的电脑配置很低，能跑吗？
A：能。Vibe Coding 的代码生成在云端完成，你的电脑只需要运行浏览器和一个轻量级编辑器。任何能正常上网的电脑都可以。
Q：学完能做什么？
A：学完你能独立做出个人主页、待办工具、小游戏、数据看板等各种网页应用，并且能部署上线分享给别人。更重要的是，你掌握了一种用AI解决问题的思维方式。
Q：Vibe Coding 会让程序员失业吗？
A：Vibe Coding 不是替代程序员，而是放大每个人的创造力。AI 是副驾驶，你才是机长。掌握 Vibe Coding 的人，会比不会的人效率高10倍。

0.8.2 Vibe Coding 是什么——三个比喻让零基础同学秒懂

一句话定义：Vibe Coding（氛围编程）就是用自然语言（说中文）跟 AI 对话，让 AI 帮你写代码、改代码、修 Bug，你在旁边负责描述需求、审查结果、做决策。你不需要先学编程语法，也能做出自己的作品。

比喻一：AI 是副驾驶，你是机长

开飞机不需要机长亲自操作每一个零件，机长负责指挥和决策，副驾驶负责执行。Vibe Coding 里，AI 就是你的副驾驶——你说"帮我写一个登录页面"，它马上动手写；但飞机往哪飞、飞得好不好、要不要调整，都由你这个机长说了算。

比喻二：不用先学造发动机，也能开车

传统学编程就像先学造发动机再开车——要先背语法、懂原理，才能写出一个程序。Vibe Coding 是直接上车——你会说"把车开快一点""左转""停在这里"，车（AI）就能动起来。你不需要成为工程师，只需要会表达需求和判断好坏。

比喻三：请了一个 24 小时随叫随到的"实习程序员"

Vibe Coding 相当于你雇了一个随时在线、反应极快、还不用发工资的实习程序员。它的缺点是偶尔会犯错、会误解你的意思、写出的代码可能不完美——所以你要像带实习生一样：说清楚要求、检查它的成果、让它反复修改。这个过程叫"迭代"，也是这门课最重要的能力。

💡 讲师提示

这三个比喻讲完后，可以当场再问一句："现在你觉得 Vibe Coding 是什么？"让 2-3 个同学用自己的话复述一遍，确认真的听懂了，再进入下一节。（第 1 章 1.2 节会从专业角度再详细定义一次，这里只需要建立直觉。）

0.8.3 Vibe Coding 能做出什么——10 个作品案例点燃兴趣

兴趣是最好的老师。给同学看"能做出什么"，比讲一百句"很有用"都有效。下面 10 个作品全部是零基础学生用这门课的方法能独立做出来的：

个人主页 / 简历
把自己的照片、介绍、作品放上网，生成一个专属链接分享给老师、同学、面试官。对应第 5 章实战项目一（手把手带做）。
待办清单 / 日程助手
记录每天要做的任务，勾选完成、按优先级分类、数据自动保存不丢失。对应第 6 章实战项目二（手把手带做）。
小游戏
贪吃蛇、2048、猜数字、记忆翻牌——上课摸鱼都能玩的网页小游戏。对应第 6 章后自由扩展。
数据看板
把课表、记账、运动打卡做成漂亮的图表面板，一眼看清趋势。对应第 4 章基础 + 第 7 章调试后。
学习打卡器
每天打卡背单词/学习，记录连续天数，逾期会有提醒。对应第 5-6 章同款技能。
问卷 / 投票收集
班级聚餐投票、活动报名，收集结果自动汇总成表格。对应第 9 章进阶。
AI 问答小助手网页
把自己的知识整理成一个网页版问答机器人，同学都能来问。对应第 9 章进阶。
读书笔记网站
把读过的书、笔记、摘抄整理成个人网站，长期积累。对应第 8 章部署后。
PPT / 文档生成助手
用 AI 帮自己和同学一键生成汇报 PPT、写报告、总结论文。对应 2.12 办公效率核心教程。
课程作业展示页
把各科作业、项目、获奖做成一个作品集网页，面试求职加分。对应第 5 章 + 第 8 章部署。
